# Gitvisha Insurance Website

A responsive React + TypeScript + Vite website for Gitvisha.

## Run in VS Code

1. Extract/open this folder in VS Code.
2. Open **Terminal → New Terminal**.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
npm run preview
```

## Logo

The official Gitvisha logo from the chat is included at:

## Before going live

The quote form is frontend-only. Connect an email service, CRM, Supabase, Formspree, or your preferred backend before publishing.

Replace the placeholder phone number, address, privacy/terms text, and any other editable business details with your firm's verified information.
